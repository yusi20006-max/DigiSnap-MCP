# DigiSnap-MCP

MCP server for comparing products, prices, sellers, availability and specifications across **Digikala** and **SnappShop**.

## Project Status

🚧 Early development

## Planned Features

- Digikala product search
- SnappShop product search
- Product normalization
- Cross-store product matching
- Price comparison
- Seller comparison
- Specification comparison
- Stock and availability comparison
- Purchase links
- Price history
- MCP tools for AI assistants

## Architecture

Digikala Adapter ─┐
                  ├─ Product Normalizer ─ Comparison Engine ─ MCP Server
SnappShop Adapter ┘
